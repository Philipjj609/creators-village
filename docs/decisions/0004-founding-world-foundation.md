## Context

project owner requires a mostly undeveloped distinctive landscape that grows through real authorized changes into the same mature village. V1 currently creates18 structures with projected terrain decoration; H01 improved production method but did not establish the final visual identity. Retain existing source, camera, auth, persistence and compatibility. Pause broader Building Genome/art expansion while reviewing the world foundation.

## Proposed decision

Adopt independent world UUID plus persisted seed/immutable version inputs; a bounded pre-generated geographic envelope; hybrid quantized heightfield/cells/sparse features and later typed surfaces; small initial activation/founder; separate ecological/admin/functional regions; persistent roads/entrances/occupancy; derived versioned navigation/render caches; same-domain-model real growth and explicitly synthetic showcases. Keep server-authoritative commands, scoped revisions, original durable receipts/current relational state and recoverable public updates. Use an explicit topology guard where access predicates are shared, not global stale checks for every operation.

Geography/permission facts remain independent of asset recipes/render LOD. Initial rendering uses existing fixed Pixi/Blender machinery with runtime terrain and bounded occlusion experiments; no claim of arbitrary3D geometry support. New v2 contracts coexist with v1 only through reviewed dispatch/catalog migration; never infer heightfields from old projected pond/tree/path data or overwrite old worlds.

## Consequences and open gates

Upfront bounded CPU/storage for finite terrain buys reproducibility and expansion continuity; verify before freezing profile. Terrain alone does not solve usable founding capacity, navigation, occlusion, authorization or mature community activity. Staged generation and shared topology guards add complexity but prevent partial worlds and disconnected concurrent edits. Finite-envelope extension is a separate constrained operation, not infinite-noise chunks.

All scales/dimensions, founding structure, actor/construction policy, v1 one-world coexistence, activation/clearing semantics and hackathon cut line remain proposals.
